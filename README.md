# LA-WBC project page

Project page for **LA-WBC: Learning-driven Adaptation of Whole-Body Control for Safe Locomotion on Uncertain Terrain**, by Hanbin Jang and Jaemin Lee. The paper has been accepted to *IEEE Robotics and Automation Letters*. The page retains the original Academic Project Page Template's Bulma layout and CSS, with a small LA-WBC-specific CSS addition.

## Files used by the page

- `index.html`: project page, research summary, results, links, and future citation section.
- `code.html`: local placeholder for the future code release.
- `static/images/hero.png`: web image rendered from the supplied `Hero_rev0929.pdf`.
- `static/images/framework.png`: framework diagram rendered from the supplied `framework.pdf` and shown at the top of **How It Works**.
- `static/images/ncstate-brick-2x2-red.png`, `symbolforicon.png`, and `logo.png`: university, department, and HIER Lab logos displayed in that order between the author affiliation and the RA-L acceptance line, without captions or card borders.
- `static/images/hardware_snapshots_05.png` and `hardware_snapshots_07.png`: the 0.5 and 0.7 m/s hardware photograph comparisons extracted from `hardware_exp_rev0728_compressed.pdf`. They contain no plots.
- `static/images/locomotion_metrics.png`: the locomotion-performance half of manuscript Table II, displayed below the side-by-side hardware snapshots. Its editable vector source is `locomotion_metrics.svg`, generated by `scripts/render_locomotion_metrics.py`.
- `static/videos/experiments/`: four lightweight, looping hardware clips derived from the supplied 0.5 and 0.7 m/s GIFs, with and without adaptation. Matching poster images are in `static/images/`.
- `static/pdfs/camera_ready_MS.pdf`: currently linked from the **Paper** button and identified on the page as an accepted manuscript. Replace this file at the same path after final revisions; the button will keep working.
- `static/videos/supp_video_revised.mp4`: linked from the **Supplementary video** download button; it is not embedded on the page.

The page is in English. No arXiv link is shown. The 2×2 hardware video grid appears at the end of Results, with LA-WBC clips outlined in blue. The four source GIFs remain in `static/images/` locally, but `.gitignore` excludes them because each is over 200 MB; the page uses the derived MP4 files instead.
The table uses the author-confirmed correction **0.221** for LA-WBC's hardware Cost of Transport at a 0.5 m/s command; the current manuscript PDF still says **0.211**. Update the manuscript before final submission. The web table uses black text throughout, with bold only on the simulation numbers indicated in the source table; hardware measurements in parentheses use regular weight. If any other table values change, edit the rows in `scripts/render_locomotion_metrics.py`, run it, and regenerate the PNG from the SVG.

## Before publication details are final

1. After submitting the final RA-L material, check the corresponding author's PaperCept workspace and email for the publication workflow. Search IEEE Xplore for the exact paper title or author names. RA-L's Rapid Posting record should have a DOI when it appears.
2. On the paper's IEEE Xplore record, use **Cite This** / **Download Citation** and select BibTeX. Use the IEEE-generated citation as the source of truth. Do not guess the volume, issue, pages, publication date, or DOI.
3. Replace the text in the `#BibTeX` section of `index.html` with the official BibTeX and add its DOI/Xplore link. Add `citation_doi`, `citation_publication_date`, and, if appropriate, `citation_pdf_url` in the page head. Add the full IEEE citation near the supplementary video download after the video is published. Add `og:url` and an absolute `og:image` URL once the project URL is known.
4. Update the linked PDF after minor revisions. Check the current IEEE author-posting requirements for an accepted manuscript, including the required IEEE copyright notice and the published citation/DOI when available.
5. When the code repository is ready, change the **Code** button's `href` in `index.html` from `code.html` to its repository URL; `code.html` can then be removed.

The current citation section deliberately avoids a provisional BibTeX entry because publication fields have not been assigned. The page reports only values from the supplied manuscript and identifies the simulation comparisons and the evaluated RL baseline.

The supplied PDF currently has **9 pages**. The author plans to bring the final PaperCept submission within the 8-page limit stated in the [RA-L final submission checklist](https://www.ieee-ras.org/publications/ra-l/final-submission-checklist/). Its searchable text also contains no IEEE copyright notice; check the [RA-L posting guidance](https://www.ieee-ras.org/publications/ra-l/faq/) before the project page goes public. The page currently links this manuscript because the author requested a working Paper download button.
